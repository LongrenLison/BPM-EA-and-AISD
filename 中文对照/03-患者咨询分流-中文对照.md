# 患者咨询分流 中文对照

对应：`models/03-patient-enquiry-routing.bpmn`

| 英文元素 | 中文含义 | 责任人 |
|---|---|---|
| Enquiry received | 收到患者咨询 | 来电处理团队 |
| Record classify and assign priority | 记录、分类并分配优先级 | 来电处理团队 |
| Enquiry type | 咨询类型？ | 来电处理团队 |
| Answer authorised administrative query | 回答获授权的行政问题 | 来电处理团队 |
| Resolve appointment query | 处理预约问题 | 门诊预约团队 |
| Answer funding or payment query | 回答资金或付款问题 | 财务团队 |
| Triage clinical concern | 分诊临床关切 | 临床专科护士团队 |
| Provide authorised clinical response | 提供获授权的临床回应 | 临床专科护士团队 |
| Record specialist support contact | 记录专科支持联络 | 临床专科护士行政支持 |
| Record response and notify patient | 记录回应并通知患者 | 来电处理团队 |
| Enquiry resolved | 咨询已解决 | 结束 |

关键规则：来电处理人员可答复简单行政信息，但不能诊断、解释检查结果或建议治疗；临床咨询（特别是紧急临床关切）必须转给合资格的临床人员；每次咨询均需记录时间、处理人、责任团队、优先级、回应及解决状态。
