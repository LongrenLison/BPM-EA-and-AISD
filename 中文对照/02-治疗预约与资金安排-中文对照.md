# 治疗预约与资金安排 中文对照

对应：`models/02-treatment-booking-and-funding.bpmn`

| 英文元素 | 中文含义 | 责任人 |
|---|---|---|
| Treatment booking request | 治疗预约请求 | 临床团队 |
| Record consent and authorise request | 记录知情同意并授权请求 | 顾问医师/获授权临床人员 |
| Request authorised | 请求已授权？ | 临床团队 |
| Unauthorised request stopped | 未授权请求被停止 | 结束 |
| Check treatment capacity | 检查治疗容量 | 治疗预约团队/外部服务 |
| External service unavailable | 外部服务不可用 | 异常事件 |
| Record pending booking and notify owner | 记录待处理预约并通知负责人 | 治疗预约团队 |
| Retry after service recovery | 服务恢复后重试 | 定时事件 |
| Assess funding arrangement | 评估资金安排 | 财务团队 |
| Record funding approval or limitation | 记录资金批准或限制 | 财务团队 |
| Advance payment required | 是否需预付款？ | 财务团队 |
| Request secure payment | 发起安全支付请求 | 外部支付服务 |
| Payment outcome | 支付结果 | 财务团队 |
| Investigate missing provider confirmation | 调查缺失的支付服务商确认 | 财务团队 |
| Notify patient and responsible team | 通知患者和责任团队 | 财务团队 |
| Authorise urgent treatment override | 授权紧急治疗例外 | 临床团队 |
| Confirm treatment appointments | 确认治疗预约 | 治疗预约团队 |
| Treatment confirmed | 治疗已确认 | 结束 |

关键规则：行政团队不得处理未完成临床授权的治疗请求；需预付款的预约通常须在付款完成后确认；已扣款但未收到确认时进入调查，不能自动再次扣款；紧急临床风险可由临床人员授权例外，之后交财务处理。
