# 转诊与首诊预约 中文对照

对应：`models/01-referral-and-first-appointment.bpmn`

| 英文元素 | 中文含义 | 责任人 |
|---|---|---|
| Referral received | 收到转诊 | 医疗秘书 |
| Check supporting information | 检查支持材料 | 医疗秘书 |
| Information complete | 信息是否齐全？ | 医疗秘书 |
| Request missing information | 请求补充缺失资料 | 医疗秘书 / 外部转诊机构 |
| Review referral clinically | 临床审查转诊 | 顾问医师 |
| Consultant decision | 顾问医师决定 | 顾问医师 |
| Referral rejected | 转诊被拒绝 | 顾问医师 |
| Referral redirected | 转诊被转介至其他专科 | 顾问医师 |
| Prepare authorised booking request | 准备已授权的预约请求 | 门诊预约团队 |
| Find suitable appointment | 查找合适预约 | 外部预约服务 |
| Slot within timeframe | 是否在临床要求时限内有时段？ | 门诊预约团队 |
| Highlight unavailable timeframe | 标记无法满足的时限 | 门诊预约团队 |
| Review pathway capacity | 审查患者路径容量 | 患者路径协调员 |
| Confirm appointment | 确认预约 | 门诊预约团队 |
| Send appointment letter | 发送预约信 | 外部通信服务 |
| Within two weeks | 是否在两周内？ | 门诊预约团队 |
| Telephone patient and record outcome | 电话联系患者并记录结果 | 门诊预约团队 |
| Appointment confirmed | 预约已确认 | 结束 |

关键规则：医疗秘书只检查材料，不能决定临床接收；只有顾问医师接受转诊后才可安排新患者预约；若预约在两周内，除发信外还需要电话联系。
